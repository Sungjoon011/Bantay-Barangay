# BantayBarangay frontend

React (Vite) screens for the Bantay-Barangay API.

1. Start the backend first (it listens on http://localhost:5000).
2. In this folder run:
   npm install
   npm run dev
3. Open http://localhost:5173 (not the index.html file).

The top bar shows "Backend online" when the API answers.
To use a deployed backend, copy .env.example to .env and set VITE_API_URL to its /api address.
